# Working with this archive

Each contribution folder should contain:

1. A README with the problem, intended change, upstream issue/MR link, and verified status.
2. Original patch or supporting files only when they can be exported accurately from the relevant source branch.
3. Test commands and results that were actually run.
4. A short changelog of review feedback and follow-up commits.

Do not copy an incomplete or stale diff and present it as the final implementation. Keep upstream project code and license notices intact when archiving source-derived files.
